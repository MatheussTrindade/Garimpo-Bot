## Como reportar uma vulnerabilidade

**Não abra issue pública.** Use o [reporte privado do GitHub](https://github.com/MatheussTrindade/Garimpo-Bot/security/advisories/new).

Inclua, se possível:
- Descrição e impacto
- Passos para reproduzir / prova de conceito
- Versão ou commit afetado

**Prazos de referência:** confirmação em até 3 dias úteis, avaliação inicial em até 7 dias.
A divulgação é coordenada após a correção, com crédito a quem reportou (se desejar).

## Escopo

- Código deste repositório e o pipeline de CI.
- **Fora do escopo:** vulnerabilidades nas fontes de dados de terceiros (CISA, NVD, FIRST,
  GitHub, abuse.ch) — reporte diretamente aos mantenedores delas.
